# 🏨 Hotel Booking Analytics Dashboard

An interactive **Power BI dashboard** built to analyze hotel booking data and generate actionable business insights. This project focuses on booking trends, cancellations, customer behavior, and hotel performance using interactive visualizations.

---

## 📌 Project Overview

The dashboard analyzes **87K+ hotel booking records** to help stakeholders understand booking patterns, guest behavior, cancellation trends, and revenue-related metrics.

---

## 🚀 Features

- 📊 Interactive KPIs
- 📅 Booking Trend Analysis
- ❌ Cancellation Analysis
- 👥 Customer Segmentation
- 🌍 Country-wise Guest Distribution
- 🏨 City vs Resort Hotel Comparison
- 🍽 Meal Preference Analysis
- 📈 Lead Time Analysis
- 🎛 Dynamic Filters & Slicers

---

## 📈 Key KPIs

- Total Bookings
- Total Cancellations
- Cancellation Rate
- Average ADR
- Total Guests
- Average Lead Time

---

## 🛠 Tools & Technologies

- Power BI
- Power Query
- DAX
- SQL
- Microsoft Excel
